collection of links that were useful for this project

TfL Unified API — https://api.tfl.gov.uk Swagger: https://api.tfl.gov.uk/swagger/docs/v1 Open data under the TfL terms.

Project NUMBAT — https://crowding.data.tfl.gov.uk 15-minute band entries/exits and link loads. Typical-day survey, published periodically. Used as an expected-demand denominator, not as observed ridership.

Darwin late-running reason codes — https://wiki.openraildata.com/index.php/Darwin:Late_Running_reason_codes_and_text National Rail, not TfL. Reference for the v2 cause taxonomy — an existing industry code list beats inventing categories.
